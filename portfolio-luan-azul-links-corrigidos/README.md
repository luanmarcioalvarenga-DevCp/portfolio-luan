# Portfólio — Luan Márcio Alvarenga de Arruda

Site de portfólio responsivo com apresentação profissional, tecnologias, projetos e links para demonstrações online.

## Abrir
Abra `index.html` em um navegador. Não requer instalação, dependências ou chave de API.

## Publicar no GitHub Pages
1. Crie um repositório público `portfolio-luan` no GitHub.
2. Envie os arquivos `index.html`, `styles.css`, `app.js` e `README.md` **na raiz** do repositório.
3. Vá a **Settings → Pages → Build and deployment**.
4. Escolha **Deploy from a branch**, `main`, `/(root)` e salve.
5. O endereço esperado é `https://luanmarcioalvarenga-devcp.github.io/portfolio-luan/`.
